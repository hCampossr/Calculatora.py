Projeto de uma calculadora simples (com soma, subtração, multiplicação e divisão entre dois valores).
Ao abrir, você estará automaticamente no menu, selecione a opção de operação com base nas representações numéricas.
Digite os valores desejados para cada operação (com separação entre cada um)
Após verificar o resultado pressione enter para voltar ao menu principal
Pressione 0 para sair
